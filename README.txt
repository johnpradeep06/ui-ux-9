ASS9 — HTML and CSS recreation

Open index.html to see all five Figma frames side by side, fitted to the window.
Open login.html to start the interactive prototype.
No build process or package installation is needed.

Screens:
  login.html          Frame — student sign in
  dashboard.html      Frame 1 — student dashboard
  academics.html      Frame 2 — attendance and assignments
  notifications.html  Frame 3 — academic notifications
  submission.html     Frame 4 — submission confirmation

styles.css contains all styling, including shared colors and spacing.
app.js adds navigation, password visibility, dialogs, notification filters,
mark-as-read, preferences, and a local assignment submission preview.
assets/ contains the original SVGs exported from Figma.

The five screens scale their original 402 x 992 artboards to fit the window without scrolling, preserving current design copy,
colors, spacing, and original SVG artwork. The overview's dark background,
labels, and links sit outside the artboards.

This is a frontend prototype. Sign-in does not authenticate, and assignment
files are never uploaded. Profile, help, and assignment dialogs are supporting
prototype interactions; they are not additional screens from the Figma file.
The dates and figures intentionally match the design, not today's date.

Source: https://www.figma.com/design/UBCqM2Ds1GbA5jXrrIaFkc/ASS9
